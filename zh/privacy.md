### ALM4GEST 隱私權政策

最後更新日: 2026年8月17日

川口貴大（@ekarunian，以下稱「營運者」）就行動應用程式「ALM4GEST」（以下稱「本應用程式」）中使用者資訊的處理方式，規定如下。

#### 1. 取得的資訊

本應用程式所取得的資訊如下。

| 資訊 | 內容 | 取得時機 |
| --- | --- | --- |
| 遊玩資料 | 各譜面的分數・評級・通關資訊・Flare等級・EX分數・遊玩次數・最後遊玩日期等 | 與e-amusement同步資料時 |
| 玩家識別資訊 | 各機種的玩家代碼（DDR代碼・SOUND VOLTEX玩家ID）・玩家名稱 | 同上 |
| 手動記錄資料 | 使用者手動輸入的分數等 | 手動輸入時（傳送方式如第3節所述） |
| 使用者設定資料 | 各譜面的備註・判定調整的設定值・課題曲的登錄・已儲存的篩選條件・自行製作的Tier表・應用程式設定 | 輸入・設定時（傳送方式如第3節・第4節所述） |
| 當機資訊 | 應用程式異常結束時的錯誤內容・發生位置・裝置機型・作業系統版本 | 應用程式異常結束時 |
| 使用狀況 | 應用程式的啟動・畫面的瀏覽・資料同步的執行與結果（對象機種・取得筆數・所需時間）・初次設定的開始與初次記錄的達成・裝置機型・作業系統版本・國家・應用程式版本・依安裝各自給予的識別碼（與廣告識別碼不同） | 使用應用程式時 |
| 廣告識別碼 | iOS的IDFA・Android的廣告ID | 顯示廣告時（僅限取得第6節的許可・同意時） |

本應用程式不會取得e-amusement的登入帳號・密碼等驗證資訊。

#### 2. 儲存位置與傳送

1. 取得的資訊會先儲存於使用者裝置內的資料庫。
2. 資料同步完成時，同步取得的遊玩資料與玩家識別資訊，會以建立全體玩家統計為目的，傳送至營運者管理的伺服器。
3. 傳送的資料儲存於非公開區域，不會以原本的形式對第三方公開・提供。
   僅有使用者自行選擇公開的Tier表（第4節）為例外。
4. 使用狀況不會傳送至營運者的伺服器，而是傳送至Google Analytics for Firebase（第7節）。
   遊玩資料・玩家識別資訊・手動記錄資料・使用者設定資料不會傳送。

#### 3. 備份

本應用程式具備在更換機種等情況下承接資料的備份功能。

1. 每次資料同步完成時，裝置內的整套遊玩資料會自動傳送至營運者管理的伺服器並儲存（包含手動輸入的記錄・玩家名稱・已儲存的篩選條件・應用程式設定・各譜面的備註・判定調整的設定值・課題曲的登錄）。
   也可以從設定畫面手動執行。
2. 儲存的資料會與本應用程式發行的復原碼連結，只有知道復原碼的人才能取出。
3. 若希望刪除已備份的資料，請依第8節附上復原碼與我們聯絡。

#### 4. Tier表的公開

本應用程式具備將使用者自行製作的Tier表分享給其他使用者的功能。
此功能僅在使用者選擇公開時才會運作。

1. 公開後，Tier表的名稱・對象機種・對象等級・各階層的名稱・譜面的配置，以及製作者的玩家名稱，會傳送至營運者管理的伺服器並儲存。
   不包含分數・通關資訊・玩家代碼。
2. 已公開的Tier表，只有知道本應用程式發行的8碼分享碼的人才能取出。
   不會透過列表或搜尋被找到。
3. 分享碼本身不會儲存於伺服器。
   伺服器僅保管轉換為無法還原的值。
4. 一個人同時能公開的Tier表最多20個。
5. 停止公開後，儲存於伺服器的Tier表會被刪除。
   但在公開期間內其他使用者已取得的副本，會留在該使用者的裝置內。
6. 僅在公開時，系統會自動檢查Tier表的名稱是否含有不適合公開的字詞。
   若有符合則無法公開。
   我們不會告知符合的是哪個字詞。
   僅在裝置內使用的Tier表不會受到檢查。
7. 最後一次被取用後滿2年的Tier表，會自動刪除。
8. 若發現已公開的Tier表有問題，請透過設定畫面的「回報開發需求・問題」與我們聯絡。

#### 5. 使用目的

傳送的資料僅用於下列目的。

1. 全體玩家統計（各譜面的平均分數・通關率・T分數・Tier表等）的彙整，以及對本應用程式使用者的配送
2. 本應用程式的品質改善（資料一致性的驗證・異常結束的原因調查・透過使用狀況的分析改善功能）
3. 從備份還原資料（使用第3節功能的情況）
4. 保管使用者選擇公開的Tier表，並配送給知道分享碼的使用者（使用第4節功能的情況）
5. 公開已彙整・統計化且無法識別個人的資訊（各譜面的通關率・分數分布・使用傾向的分析等），包含在營運者的社群帳號・網站等發布

在統計的彙整・配送階段，會將玩家代碼轉換為無法還原的雜湊值作為匿名ID，配送資料中完全不含玩家代碼・玩家名稱。
個別使用者的分數不會以可識別個人的形式配送。

#### 6. 廣告

本應用程式會顯示透過Google AdMob的廣告。

1. 為了投放廣告，AdMob可能會使用廣告識別碼（iOS的IDFA・Android的廣告ID）。
2. 在iOS上，會在首次顯示廣告之前顯示追蹤許可對話框，若未允許，則顯示不使用廣告識別碼的非個人化廣告。
3. 在歐洲經濟區等地區，會顯示Google同意管理工具的同意畫面，並依同意的範圍投放廣告。
4. 本應用程式不會將遊玩資料・玩家識別資訊提供給廣告業者，用於廣告的只有廣告識別碼。

AdMob的資料處理方式，依照[Google的政策](https://policies.google.com/technologies/partner-sites)。

#### 7. 對第三方的委託

除依法令規定的情況外，不會將取得的資訊提供・出售給第三方。
但為營運本應用程式而使用下列服務，資訊會在各自的目的範圍內被處理。

| 服務 | 目的 | 處理的資訊 |
| --- | --- | --- |
| 雲端儲存業者 | 資料的保管 | 遊玩資料・玩家識別資訊・備份資料・已公開的Tier表 |
| Google（AdMob） | 廣告的投放 | 廣告識別碼 |
| Google（Firebase Crashlytics） | 異常結束的原因調查 | 當機資訊 |
| Google（Google Analytics for Firebase） | 使用狀況的分析 | 使用狀況 |

對雲端儲存業者的委託僅限保管，該業者不會將本資料用於自身的目的。

#### 8. 資料的刪除

1. 裝置內的資料，會在解除安裝本應用程式時全部刪除。
2. 若希望刪除儲存於伺服器的資料，請附上玩家代碼與下列聯絡方式聯繫（將於合理期間內刪除）。
3. 若希望刪除備份的資料，請附上復原碼與我們聯繫。
4. 已公開的Tier表，在本應用程式中停止公開後會從伺服器刪除（第4節）。
5. 使用狀況未與玩家代碼等連結，因此無法個別刪除。
   儲存於Google Analytics的部分，會在Google所定的保存期間經過後自動刪除。

#### 9. 政策的變更

本政策的內容將視需要變更。
變更後的政策自公布於本頁面時起生效。
