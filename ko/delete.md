최종 업데이트: 2026년 8월 18일

ALM4GEST(이하 "본 앱")의 서버에 저장된 데이터의 삭제를 접수합니다.
본 앱에는 이메일 주소나 비밀번호로 가입하는 계정이 없습니다.
서버의 데이터는 다음 식별자와 연결되어 있습니다.

| 저장되어 있는 것 | 연결된 식별자 | 본 앱에서 삭제하는 방법 |
| --- | --- | --- |
| 친구 기능의 등록(친구 코드·다른 이용자와의 관계·친구에게 보여 주는 기록) | 친구 코드 | 친구 → 오른쪽 위의 '공개 범위' → 공통 → '친구 기능 그만두기' |
| 공개한 티어표 | 공유 코드 | 티어표 → 해당 표를 열기 → '공개'를 끄기 |
| 백업(단말 데이터 일체) | 복원 코드 | 아래의 이메일 신청 |
| 전체 플레이어 통계의 바탕이 되는 플레이 데이터 | 기종별 플레이어 코드(DDR-CODE·SDVX ID) | 아래의 이메일 신청 |

단말 내의 데이터는 본 앱을 삭제(언인스톨)하면 모두 사라집니다.

## 이메일로 신청하기

받는 곳: [kawaguchi.ek@gmail.com](mailto:kawaguchi.ek@gmail.com)

제목: ALM4GEST 데이터 삭제

본문에 다음 2가지를 적어 주십시오.

1. 삭제를 원하는 것(위 표 중 하나. 전부인 경우에는 '전부')
2. 해당하는 식별자(친구 코드·공유 코드·복원 코드·플레이어 코드)

식별자는 본 앱의 설정 화면과 친구 화면에서 확인할 수 있습니다.
본 앱을 열 수 없게 된 경우에는 아는 범위의 식별자만으로도 괜찮습니다.

접수 후 합리적인 기간 내에 삭제하고 완료를 회신드립니다.

## 삭제되는 범위

- 신청한 식별자와 연결된 데이터를 서버에서 삭제합니다.
- 개인을 특정할 수 없는 형태로 이미 집계된 통계(악곡별 평균 스코어·클리어율 등)는 원래 데이터로 되돌릴 수 없으므로 삭제 대상이 아닙니다.
- 이용 상황(Google 애널리틱스 for Firebase)은 플레이어 코드 등과 연결되어 있지 않으므로 개별 삭제에는 응할 수 없습니다. Google이 정한 보존 기간이 지나면 자동으로 삭제됩니다.
- 친구였던 동안 상대방의 단말로 가져간 기록은 상대방의 단말에 남습니다.
