### ALM4GEST 개인정보처리방침

최종 업데이트: 2026년 8월 6일

카와구치 타카히로(@ekarunian, 이하 "운영자")는 모바일 애플리케이션 "ALM4GEST"(이하 "본 앱")에서의 이용자 정보 취급을 다음과 같이 정합니다.

#### 1. 수집하는 정보

본 앱이 수집하는 정보는 다음과 같습니다.

| 정보 | 내용 | 수집 시점 |
| --- | --- | --- |
| 플레이 데이터 | 곡별 스코어·그레이드·클리어 정보·플레어 랭크·EX 스코어·플레이 횟수·최종 플레이 날짜 등 | e-amusement와 데이터 동기화 시 |
| 플레이어 식별 정보 | 기종별 플레이어 코드(DDR 코드·SOUND VOLTEX 플레이어 ID)·플레이어 이름 | 위와 같음 |
| 수동 기록 데이터 | 이용자가 직접 입력한 스코어 등 | 수동 입력 시(전송은 제3절과 같습니다) |
| 이용자 설정 데이터 | 채보별 메모·판정 조정 설정값·과제곡 등록·저장한 필터·앱 설정 | 입력·설정 시(전송은 제3절과 같습니다) |
| 크래시 정보 | 앱이 비정상 종료했을 때의 오류 내용·발생 위치·기기 모델·OS 버전 | 앱의 비정상 종료 시 |
| 이용 상황 | 앱의 실행·화면 열람·데이터 동기화의 실행과 결과(대상 기종·취득 건수·소요 시간)·초기 설정의 시작과 첫 기록의 도달·기기 모델·OS 버전·국가·앱 버전·설치별로 부여되는 식별자(광고 식별자와는 다른 것입니다) | 앱 이용 시 |
| 광고 식별자 | iOS의 IDFA·Android의 광고 ID | 광고 표시 시(제5절의 허가·동의가 있는 경우에만) |

본 앱은 e-amusement의 로그인 ID·비밀번호 등의 인증 정보를 수집하지 않습니다.

#### 2. 저장 위치와 전송

1. 수집한 정보는 먼저 이용자의 기기 내 데이터베이스에 저장됩니다.
2. 데이터 동기화 완료 시, 동기화로 얻은 플레이 데이터와 플레이어 식별 정보가 전체 플레이어 통계 작성을 목적으로 운영자가 관리하는 서버로 전송됩니다.
3. 전송된 데이터는 비공개 영역에 저장되며, 그대로의 형태로 제3자에게 공개·제공되는 일은 없습니다.
4. 이용 상황은 운영자의 서버가 아니라 Google 애널리틱스 for Firebase(제6절)로 전송됩니다.
   플레이 데이터·플레이어 식별 정보·수동 기록 데이터·이용자 설정 데이터는 전송되지 않습니다.

#### 3. 백업

본 앱은 기기 변경 시 등에 데이터를 이어받기 위한 백업 기능을 갖추고 있습니다.

1. 데이터 동기화가 완료될 때마다, 기기 내 플레이 데이터 일체가 운영자가 관리하는 서버로 자동 전송되어 저장됩니다(직접 입력한 기록·플레이어 이름·저장한 필터·앱 설정·채보별 메모·판정 조정 설정값·과제곡 등록을 포함합니다).
   설정 화면에서 직접 실행할 수도 있습니다.
2. 저장된 데이터는 본 앱이 발행하는 복원 코드와 연결되며, 복원 코드를 아는 사람만 가져올 수 있습니다.
3. 백업한 데이터의 삭제를 원하는 경우, 제7절과 같이 복원 코드를 첨부하여 연락해 주십시오.

#### 4. 이용 목적

전송된 데이터는 다음 목적으로만 이용합니다.

1. 전체 플레이어 통계(곡별 평균 스코어·클리어율·T점수·티어표 등)의 집계와 본 앱 이용자에 대한 배포
2. 본 앱의 품질 개선(데이터 정합성 검증·비정상 종료의 원인 조사·이용 상황 분석을 통한 기능 개선)
3. 백업으로부터의 데이터 복원(제3절의 기능을 사용한 경우)
4. 개인을 특정할 수 없는 형태로 집계·통계화한 정보(곡별 클리어율·스코어 분포·이용 경향 분석 등)의 공표(운영자의 SNS 계정·웹사이트 등을 통한 발신을 포함합니다)

통계의 집계·배포 단계에서는 플레이어 코드를 복원 불가능한 해시값으로 변환한 익명 ID를 사용하며, 플레이어 코드·플레이어 이름은 배포 데이터에 일절 포함되지 않습니다.
개별 이용자의 스코어가 개인을 특정할 수 있는 형태로 배포되는 일은 없습니다.

#### 5. 광고

본 앱은 Google AdMob을 통한 광고를 표시합니다.

1. 광고 게재를 위해 AdMob이 광고 식별자(iOS의 IDFA·Android의 광고 ID)를 이용하는 경우가 있습니다.
2. iOS에서는 광고를 처음 표시하기 전에 추적 허가 대화상자를 표시하며, 허가하지 않은 경우에는 광고 식별자를 사용하지 않는 비개인화 광고를 표시합니다.
3. 유럽경제지역 등에서는 Google의 동의 관리 도구에 의한 동의 화면을 표시하고, 동의 범위에 따른 광고를 게재합니다.
4. 본 앱의 플레이 데이터·플레이어 식별 정보를 광고 사업자에게 제공하는 일은 없으며, 광고를 위해 사용되는 것은 광고 식별자뿐입니다.

AdMob에서의 데이터 취급은 [Google의 정책](https://policies.google.com/technologies/partner-sites)을 따릅니다.

#### 6. 제3자에 대한 위탁

법령에 근거한 경우를 제외하고, 수집한 정보를 제3자에게 제공·판매하지 않습니다.
다만 본 앱의 운영을 위해 다음 서비스를 이용하고 있으며, 각각의 목적 범위에서 정보가 처리됩니다.

| 서비스 | 목적 | 처리되는 정보 |
| --- | --- | --- |
| 클라우드 스토리지 사업자 | 데이터 보관 | 플레이 데이터·플레이어 식별 정보·백업 데이터 |
| Google(AdMob) | 광고 게재 | 광고 식별자 |
| Google(Firebase Crashlytics) | 비정상 종료의 원인 조사 | 크래시 정보 |
| Google(Google 애널리틱스 for Firebase) | 이용 상황 분석 | 이용 상황 |

클라우드 스토리지 사업자에 대한 위탁은 보관만이며, 해당 사업자가 본 데이터를 자신의 목적으로 이용하는 일은 없습니다.

#### 7. 데이터의 삭제

1. 기기 내의 데이터는 본 앱을 삭제(제거)함으로써 모두 삭제됩니다.
2. 서버에 저장된 데이터의 삭제를 원하시는 경우, 아래 연락처로 플레이어 코드를 첨부하여 연락해 주십시오(합리적인 기간 내에 삭제합니다).
3. 백업한 데이터의 삭제를 원하시는 경우, 복원 코드를 첨부하여 연락해 주십시오.
4. 이용 상황은 플레이어 코드 등과 연결되어 있지 않으므로 개별 삭제에는 응할 수 없습니다.
   Google 애널리틱스에 저장된 부분은 Google이 정한 보관 기간이 지나면 자동으로 삭제됩니다.

#### 8. 방침의 변경

본 방침의 내용은 필요에 따라 변경됩니다.
변경 후의 방침은 본 페이지에 게재함으로써 효력이 발생합니다.
